# 🎬 WebApproved

A full-stack graduation project developed at Arab American University.

WebApproved is an interactive platform that combines movies, digital assets, and AI into one modern web application. Users can explore films, purchase digital assets, chat with an AI assistant, manage their personal library, and enjoy a responsive user experience.
